Always do:
1. Full viewport
2. One monumental image anchors the page; imagery is processed, never raw, you could use inspiration from the image references (halftone, dither, grain, ASCII, linework)
3. Use strong contrast in type scale. Set short display text at a monumental size and supporting metadata as small monospaced labels. Keep body text at a comfortable reading size. Avoid a page where every heading and control uses a similar medium scale. Small labels must remain clear on mobile and at increased text size.
4. Collapse row of buttons into a triple-dot menu. Turn text chips into icons
5. Numbers that actually matters to the right
6. For colors, muted works. Pick a restrained base and one accent (From the color palette references), let the data carry the color. Color should mean something, not decorate something.
7. Choose one supporting graphic system that fits the site’s subject and visual style: technical marginalia, proofing marks, industrial labels, cartographic marks, terminal records, or wayfinding signs. Use it for real information, navigation, status, or structure. Do not add it only as decoration. Do not default to technical marginalia. When creating several versions, vary the system between them. Combine two only when each has a clear and separate role.

Never do:
1. purple gradients
2. glossy 3D SaaS blobs
3. untextured stock photography
4. rounded-everything
5. friendliness
6. icon grid feature rows (please avoid emojis at all costs)
7. Inter/system-font-only typography
8. evenly-distributed
9. colorful palettes

IMPORTANT: hero images come later. DO NOT generate or source any imagery. For each version, reserve the hero slot exactly where the placement note says (<img> or background with the correct aspect and position) and fill it with a flat CSS stand-in that matches the direction's palette. Size all typography and negative space as if the described image were already there, so the real image drops in with zero layout changes. Text should be easy to read, avoid tight letter spacing. Use semibold or medium for titles and subtitles

When creating a site, match the selected imagery aesthetic then select a website reference to use it as a foundational base, use the vocabular imagery to match the feel and style. DO NOT blend directions - each site should commit fully to is aesthetic.
